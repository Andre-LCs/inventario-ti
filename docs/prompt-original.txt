Você é um desenvolvedor full-stack experiente, especializado em aplicações web responsivas, PWA, JavaScript/TypeScript, leitura de códigos de barras e integração com Google Sheets.

Quero que você desenvolva um sistema completo de inventário de computadores para ser utilizado principalmente em um celular Android.

O sistema será utilizado por apenas UMA pessoa por vez durante o inventário físico de computadores. Portanto, não quero uma arquitetura empresarial complexa, servidor pago, banco de dados pago ou sistema multiusuário.

O objetivo é ter uma solução funcional, simples, rápida e totalmente gratuita para testar e utilizar no trabalho.

==================================================

1. OBJETIVO DO SISTEMA
   ==================================================

O sistema será utilizado para realizar o levantamento físico de computadores que estão desligados, armazenados em estoque e que podem estar funcionando ou apresentar defeitos.

Para cada computador será necessário registrar:

* Número de patrimônio
* Número de série
* Marca
* Modelo
* Estado
* Situação
* Componentes encontrados
* Observações/laudo
* Data e hora do registro

O sistema deve facilitar ao máximo o trabalho utilizando a câmera do celular para ler os códigos de barras existentes no patrimônio e no número de série.

O objetivo é eliminar a maior quantidade possível de digitação manual.

==================================================
2. RESTRIÇÃO FUNDAMENTAL: CUSTO ZERO
====================================

O sistema deve ser projetado para funcionar sem custos obrigatórios.

NÃO utilizar:

* servidor pago
* VPS paga
* banco de dados pago
* hospedagem paga
* domínio pago
* serviços que exijam assinatura
* APIs pagas
* serviços proprietários pagos

Priorizar tecnologias gratuitas e/ou open source.

O sistema deve poder ser publicado gratuitamente, por exemplo, utilizando GitHub Pages ou outra solução gratuita adequada.

Não comprar domínio.

Não criar backend simplesmente por criar.

Como somente uma pessoa utilizará o sistema por vez, o Google Sheets pode funcionar como armazenamento permanente dos registros.
